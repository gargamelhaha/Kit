# Findings map (structured evidence map, cycle 1)

Owner: Synthesis & Meta-Analysis role. Inputs: `agents/reports/LIT-01…05.md`, `SOURCE_REGISTRY.csv`, `evidence/source_dedup_map.csv`.

## What this document is and is not
- **It is a structured evidence map.** It is **not a quantitative meta-analysis**. The collected sources use incompatible metrics (shared-latent fraction vs reappearance rate; refusal counts vs refusal-direction cosine; MQAR accuracy vs ARC score; judge κ vs miss rates), different models and versions, and almost never report variance. **No numbers are pooled anywhere below**; numbers are quoted side by side with their source id and are not comparable unless stated. Vote-counting of "papers for vs against" is not a result either.
- **Evidence depth:** 508 of 633 registry rows are abstract-only; no paper was read in full by any scout. Every statement is "authors report …" at best (SOURCE_SUPPORTED-level at most, and only at the depth tagged). Items marked **(abstract-level)** rest on abstracts alone; **(partial)** = selected sections read by a scout (often via a summarising tool). Nothing here is EXPERIMENTALLY_SUPPORTED by this lab, nothing has been re-run.
- **Independence judgement.** "Independent groups" is decided **only from author lists** in the registry `authors` column (my check), not from data or code overlap, which no scout inspected. Shared authors, same lab, same codebase, same benchmark, or same base model ⇒ treated as **one group** and noted. The five scout reports are logical roles of one underlying model and used the same search tools; they are not independent confirmations of anything.
- Ids are kept ids (duplicates mapped via `evidence/source_dedup_map.csv`).

## 5. Gaps this map cannot fill
- No source studies mechanisms of **Gemma 4 E2B** beyond S1/S2 (see `LITERATURE_MAP.md` (c)); all F/C items are about other models and transfer is untested.
- No full-text verification of any quantitative claim; numbers copied above are from scout reports/registry rows and are labelled by depth.
- Independence assessments are author-based only; data/code/benchmark overlap unchecked.
- A quantitative synthesis would require, per study, a common metric, per-condition variance and a pre-fixed combination rule; none of the collected sources provides all three. If lab-internal replicates (same metric, same pipeline) accumulate, pooling those is legitimate (see `methods_table.md`, Table 2).
