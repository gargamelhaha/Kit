## 4.1 Gemma 4 E2B text decoder — architecture spec (verified 2026-10-25)
Sources: HF `google/gemma-4-E2B-it` config.json/README (revision 3e22461f65e8…), transformers `main` @ 50e35cc0ca18ec19b80653690de553e6decf74f5, file `src/transformers/models/gemma4/modeling_gemma4.py` (M) and `configuration_gemma4.py` (C), Gemma 4 tech report arXiv:2607.02770v2 (T).
- Config: 35 layers, hidden 1536, 8 Q heads, 1 KV head, head_dim 256 (full-attn layers use global_head_dim 512, C `per_layer_config`), sliding_window 512, intermediate 6144, vocab 262144, GELU-tanh, tied embeddings, rms_norm_eps 1e-6, final_logit_softcapping 30.0, attention_k_eq_v=false, enable_moe_block=false. layer_types: full_attention at layers [4,9,14,19,24,29,34] (4 sliding : 1 full; last layer always full), rope: sliding theta 1e4 default; full theta 1e6 "proportional" partial_rotary_factor 0.25 (config.json; T §2: p-RoPE p=0.25).
- Norm placement (M:1344-1431, Gemma4TextDecoderLayer.forward): x -> input_layernorm -> attn -> post_attention_layernorm -> +residual; -> pre_feedforward_layernorm -> MLP -> post_feedforward_layernorm -> +residual; then PLE block; then `hidden_states *= self.layer_scalar` (M:1429, per-layer learned scalar buffer applied to the WHOLE residual stream after PLE). Gemma4RMSNorm multiplies by `weight` directly (no 1+weight offset; M:205-223). QK-norm: q_norm/k_norm (scaled) and v_norm (no scale) per head (M:1151-1250); attention scaling=1.0 (M:1166). Final `self.norm` M:1692, embed scaled by sqrt(hidden) (M:1565).
- PLE (M:1574-1594, 1700-1779, 1344-1431): `embed_tokens_per_layer` = Embedding(vocab_size_per_layer_input=262144, 35*256) scaled by sqrt(256); `per_layer_model_projection` Linear(1536 -> 35*256) * hidden^-0.5, reshaped [B,T,35,256], RMSNorm(256); combined (proj + token_embedding)*2^-0.5. Layer i receives slice [:,:,i,:] and applies: gate=Linear(1536->256)(h); act; * per_layer_input; Linear(256->1536); post_per_layer_input_norm; added to residual. PLE token lookup needs input_ids (with inputs_embeds only, HF reverse-matches against embed table or errors).
- KV sharing (M:1169-1176, 1222-1244; T §2 "20/35"): first_kv_shared_layer_idx = 35-20 = 15. Layers 0-14 own K/V. Layers 15-34 have no k_proj/v_proj/k_norm/v_norm and reuse KV of the LAST non-shared layer of the same type: sliding layers 15-18,20-23,25-28,30-33 reuse layer 13's KV; full layers 19,24,29,34 reuse layer 14's KV. (Computed from config.json by the same rule.) Queries/o_proj remain per-layer. Consequence: layers >=15 cannot be given their own K/V by intervening on their k_proj; patching K/V must be done at layers 13/14 (post-norm, post-RoPE K; V is v_norm'ed).
- "Double-wide MLP" (M:1060-1076): `use_double_wide_mlp` doubles intermediate_size (6144 -> 12288) only for KV-shared layers (15-34).
- Softcapping: logits = 30*tanh(logits/30) after lm_head (M:1854-1857, 2618-2621); no attention-logit softcapping in Gemma4 (not present in M attention).
- NOT present: AltUp, LAuReL, MatFormer activation-sparsity (grep of modeling_gemma4.py: zero hits). These ARE in Gemma 3n (modeling_gemma3n.py: Gemma3nTextAltUp, Gemma3nTextLaurelBlock, activation_sparsity_pattern).
- Residual-stream hooks: HF records `hidden_states` via output hook on each `Gemma4TextDecoderLayer` (M:1552-1556) => outputs of layer i are resid_post (after PLE and after layer_scalar). `hidden_states[-1]` is overwritten by post-final-norm `last_hidden_state` (output_capturing.py `tie_last_hidden_states`). resid_mid = input to pre_feedforward_layernorm (hook on its input), attn_out = output of post_attention_layernorm, mlp_out = output of post_feedforward_layernorm. Module path in Gemma4ForConditionalGeneration: `model.language_model.layers[i]` (matches SAE hook_name "model.language_model.layers.17").
- Memory: model.safetensors = 10,246,621,918 bytes (bf16, incl. vision/audio towers + PLE tables) vs 8 GiB RAM sandbox -> text-only/mmap/offload strategy needed.
