# E009 — Error detection from internals, decoding-time accuracy gains without retraining, early-exit compute savings
Preregistered 2026-10-25 (cycle 3) before running the model on the item set. Status: registered.

## Data
`benchmarks/factset_v1.jsonl`: single-word factual completions over 20 relations, generated by two API families and kept only
when the *other* family verified the answer (tools/gen_factset.py). Prompt = BOS + prefix; target = first token of " " + answer.
Correct ⇔ final top-1 == target token. Split: items with even index = DEV (choose any hyper-parameter), odd = TEST (report).
Model: gemma-4-E2B-it, fp32 compute, Runner(last_only_from=15), final-position residuals at all 36 indices, batched unembed.

## (a) Error detection (calibration)
Signals: S0 = final max softmax prob (baseline); S1 = final margin (top1−top2 logit); S2 = logit-lens agreement (fraction of
residual indices 26..35 whose lens top-1 equals the final top-1); S3 = first residual index from which the final top-1 stays top-1;
S4 = lens max-prob at index 28; S5 = entropy of block-25 head-0 attention at the final query.
Metric: AUROC for predicting correctness on TEST. Combined detector = logistic regression on S0..S5 fit on DEV.
- P-a1: combined detector AUROC − S0 AUROC ≥ 0.03 on TEST with bootstrap 95% CI excluding 0.
- P-a2: S2 (lens agreement) alone has AUROC ≥ S0 − 0.02 (internal stability is at least as informative as confidence).
- P-a3: S0 AUROC ≥ 0.70 (the model is not uncalibrated at the item level) — reported either way.

## (b) Decoding-time contrast (DoLa-style, no retraining)
score(t) = log p_final(t) − log p_k(t) over the plausible set {t : p_final(t) ≥ 0.1·max p_final}; k = premature residual index
chosen per item as argmax JSD(p_final || p_k) over a candidate bucket. Bucket chosen on DEV among {16–20, 21–25, 26–30}.
- P-b1: TEST accuracy(contrast) − accuracy(greedy) ≥ +2 points with exact McNemar p < 0.05.
- P-b2 (harm check): items correct under greedy that become wrong ≤ 3% of TEST.
DoLa (Chuang et al. 2023, arXiv 2309.03883) reports factuality gains on 7B+ models; not yet tested on Gemma 4 E2B here.

## (c) Early exit as compute economy
Policy: exit at the first residual index k ∈ {20..34} whose lens top-1 has lens max-prob ≥ τ; else run to the end. τ chosen on DEV
as the smallest value with accuracy loss ≤ 1 point vs full; report on TEST: accuracy change, mean fraction of layers skipped.
- P-c1: at the DEV-chosen τ, TEST accuracy loss ≤ 2 points while ≥ 15% of decoder layers are skipped on average.
Note: E2B layers ≥ 15 have no K/V, so early exit for the *last* position is cache-safe in this architecture (no missing K/V for
later tokens) — an architectural reason early exit should be cheaper here than in standard transformers.

## Controls / failure handling
Exact counts and CIs; if < 60 TEST errors the error-detection AUROCs are reported as underpowered. No item filtering after
seeing model outputs. All raw per-item signals saved.
